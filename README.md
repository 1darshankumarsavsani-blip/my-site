# my-site: 3D developer portfolio

A personal 3D interactive developer portfolio built with HTML, vanilla CSS and Three.js. It shows Java engineering, web development projects and contact info.

## Run it

Open `index.html` in a browser. No build step is needed.

## Tech stack

HTML5, CSS3, JavaScript, Three.js (3D scene).
